GEOLOGICAL MAP OF TURKEY 1:500,000 SCALE.

This map was digitised on screen in MapInfo from scans of the original 18 sheets that make up the 
1:500,000 scale Geology Map of Turkey, prepared and published by the Institute of Mineral Research and 
Exploration, Ankara - Turkey, 1961.

The data on this map was captured in three files:

1. The fault data was stored in the file entitled "Turkey 500k Faults V1.TAB"

2. The geological layer was stored in the file entitled "Turkey 500k Lithology V1.TAB"

3. The mineral occurrence data is stored in the file entitled "Turkey 500k MinOcc V1.TAB"


The completed files were warped using the Flexible Map Software and the DCW file for control.

Notes:

MinOcc Layer.

On the map sheets that were used several hand annotated mineral occurrences had been recorded. 
These were captured and attributed as such.

Lithology Layer.

A "Map_Code_unique" field has been included as some codes are the same except for case differences in characters.

A legend order field has been included to aid in the creation of ordered map legends.

A problematic unit takes up most of the Kars sheet. While there is one large unit there are several
differently coded parts of this unit with no related boundaries. It was decided to use very arbitrary boundaries
to retain the extra detail of these "internal" unit codes. It me be deemed appropriate by some users to remove these
unit boundaries.
